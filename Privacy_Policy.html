卄乇几尺ㄚ - Privacy Policy

Effective date: 23 October 2026

1. Information We Store

The Bot may store Discord user IDs, server IDs, moderator IDs, channel IDs, warning reasons, warning timestamps, server configuration, welcome message settings, autorole settings and reminder details.

2. How Information Is Used

Information is used to operate commands, maintain moderation records, save server settings, deliver reminders and provide automatic moderation and server event features.

3. Storage

The Bot uses an SQLite database named bot_data.db. The database is stored in the environment where the Bot is hosted. Its security depends on the safeguards used by the Bot operator and hosting provider.

4. Sharing

The Bot operator does not intend to sell stored personal information. Discord processes information when the Bot uses Discord's services. Hosting providers may process data as necessary to operate the Bot.

5. Retention and Deletion

Information may remain stored until deleted by the Bot operator or through an applicable feature. Removing the Bot from a server does not necessarily delete existing database records or backups.

For questions or deletion requests, contact the Bot operator through the Discord server where the Bot is used.

6. Security

The Bot operator should take reasonable steps to protect stored information, but no electronic storage system can be guaranteed completely secure.

7. Changes

This policy may be updated when the Bot's features or data practices change. The latest version will be published at this URL.

8. Contact

For privacy questions, contact the Bot operator through the Discord server where the Bot is used.
